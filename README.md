# Ahmed Ebead — Channel Scripts

كل السكريبتات اللي بتتعمل في فيديوهات قناة **Ahmed Ebead** على يوتيوب وفيسبوك، متقسّمة حسب لغة البرمجة.

All the scripts written in Ahmed Ebead's YouTube/Facebook videos, organized by programming language.

## الترتيب | Structure

```
python/
  008-organize-folder/      ← رقم الحلقة - اسم السكريبت
    organize.py
    README.md               ← بيعمل إيه، وإزاي تشغّله، ولينك الحلقة
javascript/                 ← لما يبقى فيه سكريبتات JavaScript
...
```

- كل لغة ليها فولدر: `python/`، `javascript/`، وهكذا.
- جوه كل لغة، فولدر لكل سكريبت، اسمه **رقم الحلقة - اسم قصير بالإنجليزي**.
- كل فولدر فيه `README.md`: السكريبت بيعمل إيه، وإزاي تشغّله، ولينك الحلقة.
